# DigitalGeometryProcessing

- Dijkstra: Dijkstra's Shortest Path algorithm
- sampling: Farthest Point Sampling (FPS)
- patching: patch at the intersection of 4 paths/geodesics
- Intrinsic Symmetry: Intrinsic symmetry axis detection of a 3D model
- Mesh Editing: Mesh approximation and deformation using least-squares
